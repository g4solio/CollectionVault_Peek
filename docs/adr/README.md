# Architecture decision records

One file per decision, numbered, named after the decision. Each ADR links the issue where the decision was made and gives the date, the alternatives that were weighed, and what later changes must keep. An ADR is never edited to mean something else: a new decision gets a new ADR that names the one it replaces.

CI checks that every ADR links an issue (`.github/workflows/guards.yml`). The template is `0000-template.md`.
