# Triage labels

| Label | Meaning |
|---|---|
| `needs-triage` | A maintainer has to evaluate this issue |
| `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | Fully specified; an agent can take it alone |
| `ready-for-human` | Needs a human decision or human hands |
| `wontfix` | Will not be actioned |

The five roles come from [mattpocock/skills](https://github.com/mattpocock/skills). This file maps them to the labels the tracker actually uses, so that a skill saying "apply the AFK-ready label" knows which string to apply.
